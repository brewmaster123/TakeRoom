# TakeRoom 0.6 · Ночная студия

Личная студия для iPhone с iOS 17 и новее. Проект объединяет бит, текст, основной видеодубль, опорную строку, два дабла, два бэка и до четырёх дополнительных видео. Медиа и настройки сохраняются на телефоне.

## Сборка IPA для GBox

Распакуйте содержимое ZIP в корень репозитория вместе с папкой `.github`. В корне находятся `TakeRoom.xcodeproj`, `App`, `Audio`, `Tests` и этот README.

После push запустится GitHub Actions **Build unsigned IPA** на macOS. Задача запускает локальные проверки, проверку экспорта AVFoundation, собирает приложение через Xcode и упаковывает неподписанный IPA. Можно запустить её вручную через **Actions → Build unsigned IPA → Run workflow**.

В завершённой задаче скачайте артефакт `TakeRoom-unsigned-IPA`. Внутри находится `TakeRoom-unsigned.ipa`. Подпишите его через GBox своим обычным способом. Идентификатор приложения `studio.takeroom.prototype`.

## Навигация

**Продолжить** открывает последний посещённый проект. Волны на главном экране и в плеере строятся по аудиофайлу проекта.

В **Текст** редактор находится над плеером. Нажатие на название бита открывает выбор другого файла. Кнопка с ползунками открывает название проекта, темп, тональность и метроном. Кнопка **Фрагмент** открывает выбор границ.

В **Запись** выберите основной дубль, чтобы записать даблы, бэки или дополнительные видео. Разверните **Суфлёр** для настройки текста и **Опорная строка** для записи ориентира.

В **Микс** коснитесь дорожки для регулировки громкости, включения звука и сдвига по 5 мс. Правки на этом экране сразу сохраняются в дубле. **Дорожки** открывает расширенный редактор с видео, масштабом, перетаскиванием и отменой. **Обработка, ямы и видео** открывает эффекты голосов, мастер, сайдчейн, редактирование ям и фильтр изображения. В меню **Экспорт** выберите предпросмотр, сохранение в Фото, отправку MP4 или Stems ZIP.

## Бит и текст

1. Создайте проект и загрузите MP3, M4A, WAV или другой аудиофайл, который может прочитать iPhone.
2. В окне фрагмента коснитесь волны для прослушивания. Двигайте цветные границы либо ползунки начала и конца. Нажмите **Использовать фрагмент**. Можно выбрать весь трек. Ограничение в 90 секунд снято.
3. Включите повтор и пишите текст под выбранный фрагмент. Курсор и прокрутка редактора управляются касаниями и обычными жестами редактирования iOS.
4. Анализ первых 60 секунд трека в фоне предлагает BPM в диапазоне 60–200 и тональность. При слабом результате поле остаётся пустым. Темп и тональность редактируются вручную. Кнопки ×½ и ×2 работают в пределах 60–200. Кнопка **Здесь раз** ставит опору сетки в начало выбранного фрагмента.

Автоматический музыкальный анализ может выбирать другой уровень пульса, например 82 вместо 164 BPM. Проверьте результат метрономом и при необходимости используйте ×2.

## Основной дубль по опорной строке

1. Через кнопку наушников откройте **Звук**. Выберите микрофон. Для опорной строки включите вывод на динамик iPhone и проверьте отображаемые вход и выход.
2. На вкладке **Запись** нажмите **Записать опорную строку**. Прочитайте первую строку вместе с битом, который слышен микрофону. Завершите запись после строки.
3. Выключите вывод на динамик, выберите наушники в системном меню и проверьте фактический маршрут. Снимите основной видеодубль под тот же фрагмент.
4. После записи откроется окно опорной строки. Приложение ищет бит в опорной записи, затем предлагает сдвиг для основного дубля. Анализ предложения использует первые 18 секунд.
5. При неуверенном совпадении отметьте на двух волнах начало одного и того же слова. Касание запускает звук с выбранной точки. Масштаб и начало видимого участка регулируются. Если бит в опорной записи не распознан, подгоните дорожки на слух в секвенсоре.
6. Примените сдвиг и прослушайте его в разделе **Микс → Дорожки**. Двигается бит относительно видео с голосом. Совпадение губ и голоса сохраняется, пока отдельно не меняется сдвиг основного голоса.

Автоматическое сопоставление разных исполнений первой строки экспериментальное. Предложение требует прослушивания. Возможность ручной привязки по двум отметкам доступна в том же окне.

## Даблы, бэки, суфлёр и метроном

Основной дубль, даблы и бэки запускают воспроизведение по аудиочасам. При записи каждой дополнительной голосовой дорожки звучит текущий микс без перезаписываемой партии. Новый файл заменяет предыдущую партию в проекте после успешного сохранения.

Суфлёр занимает доступную область над кнопками записи. Текст можно двигать пальцем до старта и во время записи. При отпускании пальца автопрокрутка продолжается с выбранной строки. Отсчёт проходит при неподвижном тексте, прокрутка начинается после старта бита с учётом сообщаемой iOS задержки вывода. Размер, скорость и отступ задаются на вкладке **Запись**. Скорость 0 оставляет текст неподвижным. Текст отсутствует в экспортированном видео.

При известном BPM можно включить метроном. Он звучит в наушниках во время записи и в ямах. Клик исключён из экспорта.

Дополнительный акустический тест в настройках проигрывает нерегулярную серию щелчков. Поднесите один наушник к выбранному микрофону. Стабильный результат можно сохранить для этой пары устройств. Предыдущие поправки теста «та-та-та» автоматически не переносятся.

## Дополнительные видео для монтажа

На вкладке **Запись** выберите основной дубль и откройте **Доп. видео для монтажа**. Для него можно снять до четырёх дополнительных роликов. В каждом ролике сохраняется звук микрофона. Нажатие на снятый ролик открывает меню просмотра и перезаписи. В Stems ролики помещаются как исходные MOV в отдельную папку **«Доп. видео для монтажа»**.

## Секвенсор и обработка

**Микс → Дорожки** открывает видео и шесть волн на общей временной шкале. Можно слушать весь дубль, менять масштаб и повторять выбранный участок. Выберите дорожку, двигайте волну пальцем либо кнопками по 5 мс. **Отменить** возвращает предыдущий сдвиг. **Применить** сохраняет изменения дубля. Закрытие окна отменяет неподтверждённые настройки.

У выбранного голоса доступны компрессия, EQ по низу/середине/верху, драйв и подмес дисторшна, реверберация. Обработка выполняется в этом порядке. Громкость и mute независимы для шести дорожек.

Общий микс имеет приглушение бита под основной голос, включение мастера и плотность. Мастер содержит компрессию и ограничение пиков. Сравнение мастера подготавливает две версии с выравниванием по среднеквадратичному уровню. Этот способ сравнения приближённо выравнивает воспринимаемую громкость.

Предпросмотр использует тот же звуковой процессор, что и экспорт. Волны готовятся один раз. Изменение сдвига и обработки применяется при воспроизведении. На границе ручного сдвига применяется короткое сглаживание. После перемотки или повтора история реверберации начинается заново.

## Ямы

Коснитесь волны в разделе **Ямы в бите**, задайте начало и длину и добавьте яму. При известном темпе доступны привязка к доле и длина четыре доли. Каждую яму можно изменить или удалить. Перекрывающиеся ямы работают вместе. Начало и конец имеют короткое сглаживание, голос и видео продолжаются.

## Экспорт

MP4 содержит выбранный фильтр и общий обработанный микс. Его можно сохранить в Фото или отправить через системное меню.

В корне Stems ZIP находятся девять файлов. Снятые дополнительные ролики лежат в отдельной папке.

| Файл | Содержимое |
|---|---|
| 00-video.mp4 | Видео с выбранным фильтром и без звуковой дорожки |
| 01-beat.wav | Бит с громкостью, сдвигом, ямами и сайдчейном |
| 02-lead.wav | Обработанный основной голос |
| 03-back-1.wav | Обработанный первый бэк |
| 04-back-2.wav | Обработанный второй бэк |
| 05-double-1.wav | Обработанный первый дабл |
| 06-double-2.wav | Обработанный второй дабл |
| Master.wav | Общий микс с обработкой мастера |
| Acapella.wav | Сумма пяти голосовых дорожек с их обработкой и отдельной обработкой мастера |

У основного видео и WAV общий ноль и длительность основного дубля. Экспорт WAV учитывает сохранённый сдвиг каждой дорожки. При сдвиге вправо WAV начинается с нужного количества тишины, при сдвиге влево материал до нуля обрезается. WAV — PCM 44,1 кГц, 16 бит, стерео. Отключённые партии и отсутствующие бэки дают тишину. WAV отдельных партий учитывают фейдеры и эффекты. Финальная обработка суммы содержится в Master и Acapella.

Длительность ограничена длиной исходного бита, свободным местом и ёмкостью WAV/ZIP32. Экспорт сообщает об ошибке, если архив превышает технический размер формата.

## Проверки и продолжение работы

`python3 Tests/test_audio.py` запускает проверки C-процессора, тайминга, ZIP, темпов 60/70/120/157/164/200 BPM, сопоставления сигналов и фрагмента 11:37. Локально проверено совпадение звуковых отсчётов живого предпросмотра с экспортом при одинаковых настройках.

`bash Tests/render-smoke.sh` на macOS проверяет экспорт AVFoundation, позиции импульсов, сдвиги даблов, отдельные видео со звуком и старые проекты и отсутствие аудио у видео в ZIP. Эта проверка включена в Actions.

Текущее состояние, оставшиеся проверки и план продолжения находятся в `STATUS.md`.
